## MODIFIED Requirements

### Requirement: 认证页面导航与账号创建说明

系统 MUST 保证登录页与账号创建页间的路由切换可正常渲染，MUST NOT 在过渡结束后停留于空白区域。账号创建页 MUST 提供通过图形验证码自助注册的表单及返回登录入口，不得提供无效提交或虚假的成功提示。登录页重新进入时 MUST 清除未提交的密码、表单校验错误和验证码弹窗状态，并保留既有记住账号功能；刚注册成功时 MUST 优先回填新用户名。账号创建表单、提示及返回登录按钮 MUST 提供中英双语。

#### Scenario: 从登录进入账号创建说明

- **WHEN** 用户在登录页点击「创建账号」
- **THEN** 显示用户名、密码、确认密码及注册按钮，校验后弹出图形验证码，页面不空白

#### Scenario: 返回登录初始化状态

- **WHEN** 用户输入登录信息或触发表单校验后进入账号创建页，再点击返回登录或浏览器后退
- **THEN** 登录表单正常显示，未提交的密码和校验错误被清除，验证码弹窗关闭；已记住的用户名按既有规则恢复，刚注册成功时优先回填新用户名

#### Scenario: 重复往返与直接访问

- **WHEN** 用户多次往返登录与账号创建页，或直接访问及刷新账号创建页
- **THEN** 当前路由的内容始终正确显示，返回登录入口可用

#### Scenario: 切换语言

- **WHEN** 用户通过认证页语言入口切换中文或英文
- **THEN** 账号创建表单、提示和返回登录按钮显示对应语言
