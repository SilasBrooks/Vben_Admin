## ADDED Requirements

### Requirement: 图形验证码自助注册

系统 MUST 提供匿名可访问的 POST /api/auth/register，只接受用户名、密码、确认密码、captchaId、captchaCode。用户名 MUST 为 4–32 位英文字母、数字、下划线且以字母开头；密码 MUST 为 8–64 位 ASCII 可见字符且至少含字母和数字，不得包含空白。系统 MUST 验证两次密码一致，并在任何账号写入前校验 Redis 一次性图形验证码。验证码 MUST 两分钟有效、忽略大小写、校验即销毁；缺失、错误、过期、重放 MUST 拒绝注册。

#### Scenario: 有效信息创建账号

- **WHEN** 匿名用户提交格式正确的账号信息、相同的两次密码及有效验证码
- **THEN** 创建一个启用账号，密码以 BCrypt 哈希存储，返回成功且不签发 Token 或登录 Cookie

#### Scenario: 参数不合法

- **WHEN** 用户名或密码不符合规则，或两次密码不同
- **THEN** 返回 400 与对应语言的错误，不创建账号

#### Scenario: 验证码无效或被重放

- **WHEN** 提交缺失、错误、过期或已使用的验证码
- **THEN** 返回 400，不写入账号；已参与校验的验证码不可再次使用

### Requirement: 注册唯一性及最小权限

系统 MUST 通过用户名查询和数据库唯一约束防止重复账号，并将并发唯一键冲突转换为用户名已存在的业务错误。新账号 MUST 不分配角色和部门，默认首页为 /profile；MUST NOT 从请求中读取角色、权限、状态或首页来决定新账号权限。响应 MUST NOT 暴露密码或用户实体。

#### Scenario: 重复或并发同名注册

- **WHEN** 用户名已存在，或并发同名请求通过了查询
- **THEN** 至多创建一个账号，其余返回用户名已存在错误，不返回数据库异常详情

#### Scenario: 请求伪造权限字段

- **WHEN** 请求额外携带 roleIds、status、deptId 或 homePath
- **THEN** 账号仍按服务端固定默认值创建，角色与部门为空，首页为个人中心

### Requirement: 注册限流与防重复提交

注册接口 MUST 通过 Redis 按 IP 限制每分钟最多 5 次，并以 3 秒窗口阻止重复提交。超限 MUST 返回 429，防重命中 MUST 返回 409。Redis 不可用 MUST 拒绝注册，MUST NOT 降级放行。新增公开路径 MUST 仅放行注册端点，不扩展系统管理等受保护路径。

#### Scenario: 快速重复提交与超限

- **WHEN** 同一 IP 在防重窗口内重复提交，或一分钟内超出注册次数限制
- **THEN** 相应请求返回 409 或 429，不继续创建账号

#### Scenario: Redis 不可用

- **WHEN** 验证码、限流或防重所需的 Redis 操作失败
- **THEN** 请求失败且不创建账号

### Requirement: 前端注册与登录衔接

系统 MUST 提供中英双语注册表单和图形验证码弹窗。注册字段校验通过后 MUST 获取新验证码；验证码可主动刷新，获取失败可重试，注册失败后 MUST 清空验证码输入并获取新码。提交中 MUST 阻止重复确认。成功后 MUST 返回登录页，显示成功提示并仅回填新用户名，密码 MUST 为空，不自动登录；MUST NOT 将密码放入 URL 或持久化存储。

#### Scenario: 注册成功返回登录

- **WHEN** 注册接口返回成功
- **THEN** 导航到登录页，显示成功提示并回填新用户名（优先于旧记住账号），密码与验证码状态为空

#### Scenario: 注册失败重试

- **WHEN** 注册被拒绝或验证码获取失败
- **THEN** 展示错误，保留注册账号信息，提供重新获取验证码及再次提交的入口
