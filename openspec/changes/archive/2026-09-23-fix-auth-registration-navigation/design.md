## Context

认证布局以 Transition / KeepAlive 包裹路由，按组件名称 Login 缓存登录页。业务登录页包含验证码弹窗，并将布局属性传给内层表单。实际浏览器复现从登录进入注册后仅保留页头和页脚。注册提交为占位实现，认证 API 未提供自助注册接口。

## Goals / Non-Goals

- Goals：创建账号入口有明确说明；路由往返始终可见；离开登录页后不保留密码、校验错误及验证码状态；保留记住账号功能。
- Non-Goals：不增加公开注册、默认角色、审批流程或修改其他认证方式。

## Decisions

- 业务登录页不匹配框架 Login 缓存白名单，以路由卸载、重新挂载恢复干净状态，不改动公共布局包。
- class 与 data-side 透传给业务页面的唯一根节点，使布局和过渡作用于同一元素。
- 注册页使用单根说明内容及 VbenButton 返回登录，不显示无法提交的账号密码表单。
- 新文案放入应用 account 语言包，中英同构，避免修改框架认证语言包。

## Risks

- 退出登录页会丢弃未提交的输入，这是避免缓存密码的预期行为；已记住的用户名仍由公共登录组件恢复。
- 自助注册尚未开放，说明页应明确管理员创建账号，不能显示注册成功。
- 页面切换需通过浏览器检查进入、返回、重复往返与刷新后的实际可见性。
