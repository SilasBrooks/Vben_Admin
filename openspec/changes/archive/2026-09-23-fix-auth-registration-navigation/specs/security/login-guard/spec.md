## ADDED Requirements

### Requirement: 认证页面导航与账号创建说明

系统 MUST 保证登录页与账号创建页间的路由切换可正常渲染，MUST NOT 在过渡结束后停留于空白区域。未开放自助注册时，账号创建页 MUST 明确告知用户联系管理员创建账号，不得提供无效注册提交或虚假的成功提示。登录页重新进入时 MUST 清除未提交的密码、表单校验错误和验证码弹窗状态，并保留既有记住账号功能。账号创建说明及返回登录按钮 MUST 提供中英双语。

#### Scenario: 从登录进入账号创建说明

- **WHEN** 用户在登录页点击「创建账号」
- **THEN** 账号创建页显示联系管理员的说明及返回登录按钮，页面不空白且不提供无效注册表单

#### Scenario: 返回登录初始化状态

- **WHEN** 用户输入登录信息或触发表单校验后进入账号创建页，再点击返回登录或浏览器后退
- **THEN** 登录表单正常显示，未提交的密码和校验错误被清除，验证码弹窗关闭；已记住的用户名按既有规则恢复

#### Scenario: 重复往返与直接访问

- **WHEN** 用户多次往返登录与账号创建页，或直接访问及刷新账号创建页
- **THEN** 当前路由的内容始终正确显示，返回登录入口可用

#### Scenario: 切换语言

- **WHEN** 用户通过认证页语言入口切换中文或英文
- **THEN** 账号创建说明和返回登录按钮显示对应语言
