## ADDED Requirements

### Requirement: 登录失败关闭验证码弹窗

登录页 MUST 在实际登录请求失败后关闭验证码弹窗并清理本次待提交凭据，保留错误提示与可编辑的账号密码表单。用户再次点击登录时 MUST 获取新的验证码。仅验证码输入格式校验不通过时 MUST 保持弹窗打开且不提交登录请求。共用验证码组件 MUST 保持忘记密码请求失败后刷新验证码并允许继续重试的行为。

#### Scenario: 登录请求失败

- **WHEN** 登录接口因密码错误、验证码错误或过期、限流或网络异常拒绝请求
- **THEN** 显示已有错误提示并关闭验证码弹窗，用户可修改登录表单，再次登录时加载新验证码

#### Scenario: 验证码输入格式不正确

- **WHEN** 用户确认空验证码或格式不正确的验证码
- **THEN** 保持弹窗并显示字段校验错误，不调用登录接口

#### Scenario: 找回密码验证失败

- **WHEN** 找回密码流程的验证码确认请求失败
- **THEN** 弹窗保持打开，刷新验证码以便重试
