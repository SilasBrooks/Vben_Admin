# delta: ai/assistant

## ADDED Requirements

### Requirement: 代码块复制与长代码折叠

助手消息中的代码块 MUST 在块头部展示语言标识（围栏标注的语言；未标注语言时展示 `text` 或留空），并提供复制按钮，点击后将代码块完整内容写入系统剪贴板并给出短暂成功反馈。复制 MUST NOT 包含语言标签与按钮自身文本。

超过 20 行的代码块 MUST 默认折叠（限制展示高度并给出可感知的展开入口），用户 MUST 能展开完整内容并再次收起。折叠状态 MUST NOT 影响复制功能（折叠态复制的是完整代码）。

代码块结构 MUST 经既有 XSS 防线（解析器禁用原始 HTML + DOMPurify 消毒）后注入，注入的按钮与标签 MUST NOT 引入脚本执行风险。

#### Scenario: 语言标签与复制

- **WHEN** 模型回复包含 ```sql 代码块，用户点击复制按钮
- **THEN** 块头部显示 `sql` 语言标识，完整 SQL 文本进入剪贴板，按钮短暂显示复制成功态

#### Scenario: 长代码默认折叠

- **WHEN** 模型回复包含 25 行的代码块
- **THEN** 代码块默认折叠为受限高度（含展开入口），点击展开后完整可见，可再次收起；折叠态下点击复制仍得到完整 25 行内容

#### Scenario: 短代码不折叠

- **WHEN** 模型回复包含 8 行的代码块
- **THEN** 代码块完整展示，不出现折叠入口

#### Scenario: 注入结构不逃逸

- **WHEN** 代码内容本身包含 `<button>`、`<script>` 等文本
- **THEN** 代码内容按转义文本展示，页面不出现可交互的多余按钮、不执行脚本

### Requirement: 消息区自动滚动跟随

流式输出与消息更新引发的列表增长，MUST 仅在用户视口位于消息区底部附近（阈值内）时自动滚动到底；用户向上翻阅历史时 MUST NOT 被强制拉回底部，用户滚回底部附近后自动恢复跟随。用户主动发送消息、点击建议项产生的新对话轮次 MUST 滚动到底部展示。

#### Scenario: 流式中上翻不被拉回

- **WHEN** 模型正在流式输出，用户向上滚动消息区阅读历史
- **THEN** 输出继续但视口保持用户所在位置，不自动跳回底部

#### Scenario: 滚回底部恢复跟随

- **WHEN** 用户在流式输出中向上翻阅后，将消息区滚回底部附近
- **THEN** 后续输出重新自动滚动跟随

#### Scenario: 新发消息定位底部

- **WHEN** 用户发送一条新消息或点击建议项
- **THEN** 消息区滚动到底部，新消息与随后出现的回复气泡可见
