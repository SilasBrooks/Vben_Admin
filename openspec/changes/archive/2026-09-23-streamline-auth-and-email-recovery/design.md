## Context

用户要求后台仅使用管理员创建的账号，并通过已绑定邮箱自助找回密码。既有 sys_user.email 只是可编辑的联系信息，不能作为已验证身份凭据。

## Goals / Non-Goals

- Goals：移除入口、页面和接口，无法通过旧路径继续自助注册；保留既有登录与管理员账号管理。
- Goals：安全邮箱绑定、图形验证码保护发信、邮件验证码重置密码；精简认证界面并使用项目文案。
- Non-Goals：删除既有业务账号、代开通邮箱或购买邮件套餐、修改公共框架组件。

## Decisions

- 使用 AuthenticationLogin 的 showRegister 配置关闭入口，删除业务注册页面与路由。
- 删除注册专用后端实现及 JWT 白名单，旧匿名 POST /api/auth/register 按受保护路径返回 401，OpenAPI 不再发布此接口。
- 清理注册 API、内存状态、文案及测试，保留登录组件单根节点与不缓存修复。
- 清理构建输出并重启本项目后端，避免已经删除的注册类仍被开发服务加载。
- 安全邮箱单独存入 sys_user_recovery_email（user_id 主键、外键删除级联），与普通联系邮箱隔离；Mapper 放 auth.mapper。绑定发送与确认均校验当前密码，仅本人可操作。
- 验证码随机 6 位、5 分钟有效、最多 5 次尝试，校验成功通过 Redis Lua 原子销毁。按用途隔离，挑战绑定用户、邮箱和 token 版本；发信每账号 60 秒冷却，接口按 IP/用户限流。
- 找回发送接口对不存在、停用或未绑定账号返回相同提示及随机 challengeId，避免泄露账号/邮箱；验证码仅发到服务端已验证邮箱。重置时再次校验用户、邮箱、token 版本，事务更新 BCrypt 密码并 bump token 版本。
- SMTP 使用环境变量配置，凭据不入库不入 Git。未配置不伪造发送成功；测试使用模拟邮件发送器，不向真实第三方发信。
- 登录仅保留账号密码、记住账号和忘记密码。认证页文案为“贵源管理平台 / 让业务协同更顺畅，让日常管理更高效”，提供英文版本。

## Risks

- 已打开的旧注册地址通过现有路由守卫回到登录或通用未找到页面，不再提供注册表单。
- 不能只隐藏入口：通过实际接口和 OpenAPI 检查确认后端注册能力已移除。
