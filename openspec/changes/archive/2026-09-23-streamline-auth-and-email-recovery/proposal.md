## Why

后台管理系统的账号应由管理员统一创建；现有忘记密码为占位页，用户需要通过已验证邮箱找回密码，并精简登录方式与替换通用模板文案。

## What Changes

- 隐藏登录页创建账号入口，删除注册路由、页面、API、注册成功回填状态及专用语言包。
- 删除公开注册 Controller、Service、DTO、注册测试和 JWT 放行路径，保留登录验证码。
- 保留登录页重新进入时清理密码、校验及弹窗状态的修复，更新 README 和能力规格。
- 个人中心增加安全邮箱绑定，通过当前密码和邮箱验证码确认；未验证的联系邮箱不能用于找回密码。
- 找回密码使用账号、图形验证码和已绑定邮箱验证码，重置后使旧令牌失效。
- 接入可配置 SMTP（不内置收费供应商），增加 Redis 验证码、发送冷却与尝试限制；无 SMTP 配置时明确提示联系管理员。
- 移除手机号、扫码和第三方登录入口及对应占位页面，采用贵源项目文案。

## Capabilities

### New Capabilities

- `security/email-recovery`：安全邮箱绑定、一次性邮件验证码及密码找回。

### Modified Capabilities

- `security/login-guard`：登录页不再提供自助创建账号入口，保留正确渲染与状态初始化。
- `security/self-registration`：撤销自助注册要求，明确后台不提供公开注册能力。
- `system/user-profile`：个人中心增加安全邮箱设置。

## Impact

- 前端业务应用认证页面、路由、认证 API、store、中英语言包。
- 后端公开注册实现、认证白名单及注册专用测试；无需修改数据库和已有账号。
- 管理员用户管理功能与登录验证码保持原有行为。
