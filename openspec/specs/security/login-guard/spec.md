# 登录安全防护能力规格（security/login-guard）—— 主规格

## Purpose

为登录与 AI 对话等敏感接口提供纵深防护：服务端图形验证码阻挡脚本自动化、按用户名与 IP 的失败锁定阻挡密码爆破、声明式限流阻挡接口滥用。三道防线均为应用内存态（单实例语义），多实例部署时须迁移集中式存储。

## Requirements

### Requirement: 服务端登录验证码

系统 MUST 在服务端生成并校验图形验证码：`GET /api/auth/captcha` 返回 captchaId 与 base64 PNG 图片（4 位字符，2 分钟有效，一次性使用）；登录请求 MUST 携带 captchaId 与 captchaCode，服务端 MUST 在校验密码前校验验证码，验证码错误或过期 MUST 拒绝登录且不计入账号失败锁定。验证码状态 MUST 在校验后立即失效（防重放）。dev profile MUST 提供 `vben.captcha.echo-enabled` 联调回显开关（生产禁止开启）。

#### Scenario: 正确验证码可完成登录

- **WHEN** 用户获取验证码后在有效期内输入正确的码并提交正确账号密码
- **THEN** 登录成功，该验证码立即失效（重复使用被拒绝）

#### Scenario: 错误/过期/缺失验证码被拒绝

- **WHEN** 登录请求的验证码错误、过期或缺失
- **THEN** 返回 400「验证码错误或已过期」，不进行密码校验，失败锁定计数不增加

### Requirement: 登录失败锁定

系统 MUST 按用户名与 IP 两个维度统计登录失败：15 分钟窗口内失败达 5 次 MUST 锁定 15 分钟，期间登录请求无论凭据正确与否 MUST 返回 429 并提示剩余等待时间；登录成功 MUST 清零对应计数。锁定检查 MUST 发生在验证码校验之前。

#### Scenario: 连续失败触发锁定

- **WHEN** 同一用户名在 15 分钟内连续 5 次密码错误
- **THEN** 第 6 次起即使密码正确也返回 429 与剩余等待时间，直到锁定解除

#### Scenario: 成功登录清零计数

- **WHEN** 用户在某次失败后成功登录
- **THEN** 该用户名与 IP 的失败计数清零，不影响后续锁定判定

### Requirement: 接口限流

系统 MUST 提供声明式限流能力（`@RateLimit` 注解 + AOP，固定窗口）：认证接口按 IP 限流（login 10 次/分、captcha 30 次/分），AI 对话接口按登录用户限流（10 次/分）。超限 MUST 返回 429。IP 解析 MUST 兼容 X-Forwarded-For 反代场景。

#### Scenario: 登录接口超限被拒

- **WHEN** 同一 IP 在 1 分钟内向 /api/auth/login 发起超过 10 次请求
- **THEN** 超出部分返回 429，窗口过后自动恢复

#### Scenario: AI 对话按用户限流

- **WHEN** 同一登录用户 1 分钟内发起超过 10 次 AI 对话
- **THEN** 超出部分返回 429，不影响其他用户

### Requirement: Redis 集中存储

验证码、失败锁定、限流窗口的状态 MUST 存于 Redis（各状态 MUST 设置与业务时限一致的过期时间，不得永久驻留）；服务重启后进行中的锁定/限流窗口 MUST 保持有效；多实例部署 MUST 天然共享上述状态。Redis 连接不可用时，验证码签发、登录、被限流接口 MUST 快速失败并返回明确错误，MUST 不得静默降级为放行。

#### Scenario: 重启后锁定状态保持

- **WHEN** 某账号已触发登录锁定（429），此后后端服务重启
- **THEN** 重启后该账号仍处于锁定状态，登录继续返回 429 直至 Redis 中的窗口过期

#### Scenario: Redis 不可用快速失败

- **WHEN** Redis 宕机时用户请求验证码或登录
- **THEN** 接口返回明确错误（500/503 提示系统暂不可用），不会在无验证码校验的情况下放行登录

#### Scenario: 多实例共享限流计数

- **WHEN** 两台后端实例共同承接流量，同一 IP 在 1 分钟内跨实例累计向 /api/auth/login 发起超过 10 次请求
- **THEN** 超出部分返回 429（计数来源于共享的 Redis，而非各实例独立计数）

### Requirement: 后台登录页面与账号来源

系统 MUST 使用管理员创建的账号登录，登录页 MUST NOT 显示创建账号或自助注册入口。系统 MUST 移除业务注册路由及页面。登录页 MUST 正常渲染且重新进入时清除未提交的密码、校验错误和验证码弹窗状态，并保留既有记住账号功能。中文和英文登录界面 MUST 遵守相同的入口限制。

#### Scenario: 登录页面不提供注册

- **WHEN** 用户打开中文或英文登录页
- **THEN** 页面正常显示登录表单且不存在创建账号入口

#### Scenario: 旧注册地址不再可用

- **WHEN** 用户直接访问旧地址 /auth/register
- **THEN** 由既有路由守卫或未找到页面处理，不显示注册表单

#### Scenario: 返回登录初始化状态

- **WHEN** 用户离开登录页后重新进入
- **THEN** 未提交的密码、校验错误与验证码弹窗状态清除，已记住的用户名按既有规则恢复

### Requirement: 登录失败关闭验证码弹窗

登录页 MUST 在实际登录请求失败后关闭验证码弹窗并清理本次待提交凭据，保留错误提示与可编辑的账号密码表单。用户再次点击登录时 MUST 获取新的验证码。仅验证码输入格式校验不通过时 MUST 保持弹窗打开且不提交登录请求。共用验证码组件 MUST 保持忘记密码请求失败后刷新验证码并允许继续重试的行为。

#### Scenario: 登录请求失败

- **WHEN** 登录接口因密码错误、验证码错误或过期、限流或网络异常拒绝请求
- **THEN** 显示已有错误提示并关闭验证码弹窗，用户可修改登录表单，再次登录时加载新验证码

#### Scenario: 验证码输入格式不正确

- **WHEN** 用户确认空验证码或格式不正确的验证码
- **THEN** 保持弹窗并显示字段校验错误，不调用登录接口

#### Scenario: 找回密码验证失败

- **WHEN** 找回密码流程的验证码确认请求失败
- **THEN** 弹窗保持打开，刷新验证码以便重试
